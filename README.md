# WorkSpace Connect

Site web de réservation de salles de coworking.

## Technologies utilisées
- HTML / CSS
- PHP
- MySQL
- XAMPP

## Prérequis
- XAMPP installé (Apache + MySQL)
- Un navigateur web

## Installation

1. Cloner le dépôt :
git clone [URL du dépôt]

2. Copier le dossier dans `htdocs` de XAMPP

3. Démarrer Apache et MySQL dans XAMPP

4. Aller sur phpMyAdmin et créer une base de données `workspace_connect`

5. Importer le fichier SQL avec les tables `salle` et `reservation`

6. Accéder au site : `localhost/Workspace-connect`

## Pages
- `index.php` — Page d'accueil
- `salles.php` — Liste des salles
- `salle.php` — Détail d'une salle
- `reservation.php` — Formulaire de réservation
- `confirmation.php` — Confirmation de réservation
